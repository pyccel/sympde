Public API
==========

The :mod:`sympde.api` package provides the supported flat namespace for
user-facing objects. For example:

.. code-block:: python

   from sympde.api import Cube, Mapping, Constant
   from sympde.api import ScalarFunctionSpace, elements_of
   from sympde.api import BilinearForm, LinearForm, Norm

The complete namespace is listed below. These objects are also documented and
indexed at their defining modules, so this page does not create duplicate
cross-reference targets.
